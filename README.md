# KasKu.ID — Aurora Liquid Glass (Phase 1–2)
Stack: React + TypeScript + Vite + Tailwind v4 + Zustand + Recharts + date-fns + Lucide.
## Jalankan
npm install && npm run dev   # build: npm run build
## Sudah jalan
Design tokens glass, Light/Dark (tersimpan), layout responsif (sidebar / bottom nav), Dashboard (kartu, grafik arus kas, anggaran, transaksi, tujuan), logika keuangan integer, data layer (store) terpisah dari UI.
## Belum (Phase 3–5)
CRUD transaksi + modal + form (RHF/Zod), halaman Akun/Anggaran/Tujuan/Perencanaan/Aset/Utang/Travel/Laporan, toast, filter periode, export. Semua data masih lokal (tanpa backend).
